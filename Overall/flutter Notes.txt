-> class MyApp extends StatelessWidget
	
	it Exactly like inheritance MyApp (Name of the widget) and extends means it get a information for MyApp from StatelessWidget
	
-> Widget
	
	Flutter has two types of widgets.
	
		Stateless Widget -> Once it is created never changes Eg : Company Logo,About Us page,Static image,Terms and Conditions
		
		Stateful Widget -> Can change while the app is running Eg : Counter,Login Screen,Shopping Cart,Chat,WhatsApp,Instagram Feed
		
main() -> main() is the entry point of a Flutter application. Execution starts from main().

runApp() -> runApp() tells Flutter which widget should be displayed first on the screen. It starts the Flutter UI by loading the root widget.

Example Code : 

		import 'package:flutter/material.dart';

		void main() {
		  runApp(const MyApp());
		}

		class MyApp extends StatelessWidget {
		  const MyApp({super.key});

		  @override
		  Widget build(BuildContext context) {
			return MaterialApp(
			  home: Scaffold(
				appBar: AppBar(
				  title: const Text("My First App"),
				),
				body: const Center(
				  child: Text("Welcome to Flutter"),
				),
			  ),
			);
		  }
		}
		
1) build() -> Widget build(BuildContext context) -> Eg in HTML <html><body></body></html>
2) return MaterialApp( -> This is the root of almost every Flutter app. 
						  Think of it as the application container.
						  It provides features like:

							Navigation
							Themes
							Fonts
							Routing
							Material Design support

							Without it, your app loses many built-in Material features.
							
3) Scaffold -> Think of it as your screen template and it is structure of a screen.

		 Like building a house:
			House

			Roof
			Rooms
			Kitchen
			Bathroom
		
		Flutter screen:
			Scaffold

			AppBar
			Body
			Floating Button
			Drawer
			Bottom Navigation
			
4) appBar: AppBar( -> This creates the top bar. (It is html <title> tag)
5) body -> Everything you want to display goes inside the body. Eg : Login screen,Customer list,Images,Buttons,Forms.
6) Center -> This places its child exactly in the middle of the screen.
7) Text -> Text("Welcome to Flutter") (It is html <p> tag)
